# 🧮 Calculator App

A simple calculator built using **HTML, CSS, and JavaScript**.

## ✨ Features
- Basic arithmetic operations
- Keyboard input support
- Dark & Light mode
- Calculation history (saved)
- Responsive design

## 📂 Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Download or clone the repository
2. Open `index.html` in your browser
